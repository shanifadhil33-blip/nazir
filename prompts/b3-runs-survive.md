# B3: Runs that survive (Nazir). Backend, NO new scope, no redesign.
From the finish plan, chunk B3. Done when fault injection tests pass and no run is ever left "running".
1. Plan cancel in the app: an owner or quality reviewer can cancel a proposed or approved plan and a queued or running run from the existing UI (small button in the current style, EN and AR copy in messages/*.json with key parity). Server side role check, audit entry, idempotent. Reuse existing cancel logic if any (there is a hand script scripts/cancel-one.mjs in the main repo used Oct 24 for reference only).
2. Resumable runs: if a step fails because the DB connection drops or a step hits the 120 s timeout, the run must not stay "running" forever. Use the existing queue/heartbeat: a stale step (no heartbeat past a bound) is retried once, then the case is marked inconclusive with a reason, and the run finishes. Completed cases are never rerun.
3. Clear messages (EN and AR, plain words, no dashes) for: daily model cap reached, all model providers down, agent unreachable, step timeout. Map them in src/server/http/errors.ts style and show them where run status is shown.
4. Per user daily run cap for strangers on the public link: a signed in user may start at most N runs a day across their workspaces (N from an existing config style constant, default 10; the 300 calls a day global cap stays). Count server side, return a clear coded error. Do not apply it to the demo workspace reset cron.
Rules: no env, vercel.json, auth config changes. Avoid migrations; if one is truly required, keep it additive and small (new nullable columns or a function), follow the numbering in db/migrations, and add a PGlite test on real migrations like tests/roles/database.test.ts. Tests with fault injection (DB throw mid step, timeout, provider down, cap) without live network or model calls. First investigate and plan briefly, then implement, then pnpm lint, pnpm typecheck, pnpm test, fix what you broke. Do not commit. End with files changed, whether a migration was added, and anything left undone.
